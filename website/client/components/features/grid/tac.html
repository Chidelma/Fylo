Everything you need

Complexity traded for clarity.

Git-like version control, SQL query surfaces, field-level encryption, and durable queues — in one standalone binary with drop-in clients for {clientCount} languages.

Storage

Documents are truth

Each document is one canonical JSON file on disk, sharded by the trailing characters of its creation TTID. Easy to inspect, debug, back up, and rebuild from.

Indexing

Zero-payload prefix indexes

Path-encoded key-only index entries in an mmap'd sorted catalog. Queries narrow by binary search, then hydrate only matching documents.

Query

SQL + NoSQL APIs

Query with a JSON operation protocol — put, find, patch, join — or plain SQL over the same engine. Exact, range, prefix, and trigram strategies.

Versioning

Git-like version control

Branch, commit, diff, merge, and restore your document store. Auto-commit on writes with content-addressed, deduplicated snapshots.

Queue

Serverless without a broker

Durable topics, independent consumer groups, visibility leases, delayed retries, dead letters, and one-batch decorators in every native SDK shim.

Distribution

One self-contained binary

Download a single executable — no runtime, no daemon, no native addons. Every native shim can give its child a scoped .env file or map, so independently configured roots can share one application safely.

Security

Encryption & POSTIX access

AES-GCM field encryption with HMAC blind indexes, per-record POSIX UID/GID/mode enforcement, and trusted group membership.

Recovery

Filesystem snapshots

Quiesce the writer, copy the complete root with native metadata intact, then verify and restore into a new path. Remote copy and synchronization remain deployment choices outside the engine.

Architecture

No server, no protocol

Every client owns its database directly — the binary on desktop, OPFS on the web, or a user-selected folder through File System Access. Browser queries can run in a worker with Wasm acceleration. Nothing listens on a port.

Interop

One protocol, many languages

A compiled executable speaks a JSON machine protocol tested against Python, Ruby, PHP, Dart, Java, C#, C++, Swift, Kotlin, and Rust.
