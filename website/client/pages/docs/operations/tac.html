Native configuration

Environment variables consumed by the native Rust engine and its release tooling.

Environment

Variable Purpose Default
FYLO_ROOT Filesystem root for collections ./.fylo-data
FYLO_SCHEMA Directory containing JSON validation schemas —
FYLO_STRICT Validate documents with chex before writes —
FYLO_ENCRYPTION_KEY AES-GCM key for $encrypted fields (≥32 chars) —
FYLO_CIPHER_SALT Salt for blind index derivation —
FYLO_LOGGING Enable logging ("1") —
FYLO_VERIFY_PROVENANCE Require signed artifact provenance during install —

Process model

The fylo executable is the only native engine. JavaScript and the other language packages are thin NDJSON clients and never open a root directly. Use --exclusive-root for long-lived processes that require one authoritative owner.
