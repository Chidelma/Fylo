Error codes

Every failed machine response carries a non-empty error.code. The set is additive — new codes may appear in later releases, and an existing code keeps its meaning forever. Branch on the code, never on the message text.

Code Meaning Retry guidance
EBADREQUEST The request shape, field types, access object, or page options are invalid. Do not retry; fix the request.
EUNSUPPORTEDOP The operation is unknown to this runtime. Do not retry; check the handshake capabilities.
EINVALIDDOCID The supplied document ID is not a valid TTID. Do not retry; fix the ID.
EARRAYOFOBJECTS The document contains an array of objects, which the data model rejects. Do not retry; restructure the document.
EACCES The access context is not permitted to perform the operation. Do not retry with the same identity.
EQUEUE_INVALID A queue identity, option, or idempotency-key reuse is invalid. Do not retry without correcting the request.
EQUEUE_RECEIPT A queue receipt is incorrect, expired, or superseded. Do not acknowledge as that worker.
EQUEUE_LIMIT A queue message, claim, delay, attempt, state, or read limit was exceeded. Reduce the requested resource.
EDECRYPTFAILED An $encrypted field could not be decrypted with the configured key. Do not retry; fix the key configuration.
EINVALIDCURSOR The pagination cursor is invalid, expired, or from another process. Restart the traversal from page one.
EROOTLOCKED Exclusive root ownership was unavailable — another process holds the lease. Fail over per your supervisor policy.
EROOTLEASELOST Exclusive root ownership was lost after it had been acquired. Fail over per your supervisor policy.
EFRAME_UTF8 The request frame was not valid UTF-8. Fix the encoder; the loop resumes at the next frame.
EFRAME_JSON The request frame was not a well-formed JSON object. Fix the request; the loop resumes at the next frame.
EFRAME_DUPLICATE_KEY The request frame contained a duplicate object key. Fix the request; the loop resumes at the next frame.
EFRAME_REQUEST_TOO_LARGE The request exceeded the negotiated maximum request size. Split the work or raise the limit at startup.
EFRAME_RESPONSE_TOO_LARGE An unpaged response would exceed the negotiated maximum response size. Use a paged query on a persistent loop.
EFRAME_TRUNCATED The final frame was incomplete at EOF; the loop ends. Retry only after starting a new child process.
EQUERYLOOPREQUIRED The paged query contract requires a persistent loop. Reissue on a loop started with exec --loop.
EQUERYITEMTOOLARGE A single query result item cannot fit inside the response frame. Do not retry; the document exceeds the frame contract.
EQUERYSNAPSHOTTOOLARGE The query snapshot exceeded its 1 GiB storage cap. Narrow the query.
ENATIVE_IO Native filesystem I/O failed, including disk pressure or xattr operations. Treat a mutation as ambiguous; inspect the cause before retrying.
EUNKNOWN An engine failure without a more specific classification. Treat conservatively; inspect error.message diagnostically.

Storage-level codes

Failures raised below the protocol layer may carry additional stable codes — for example FYLO_COLLECTION_NOT_FOUND. Those retain their meaning across releases under the same additive policy, so they are equally safe to branch on.

In-process errors

The Node and browser APIs throw typed errors rather than returning a response envelope. A denied operation throws FyloPermissionError with code === 'EACCES'; the code values are the same set documented above, so error handling ports between the two surfaces without a translation table.
